# Code of Conduct

HealthyFood follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, respectful and constructive. Harassment, personal attacks and discriminatory language are not tolerated. Nutrition and body image are personal topics, so please avoid shaming language about food choices or bodies.

Report unacceptable behaviour by opening a private report to the maintainers (GitHub → Security → Report a vulnerability, or contact a maintainer directly). Maintainers will review every report and may remove content or contributors that break these rules.
